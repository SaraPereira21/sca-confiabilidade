# SCA — Sistema de Confiabilidade de Ativos

Versão DEMO para validação acadêmica da metodologia estatística aplicada à confiabilidade.

## Escopo
- Análise de vida com falhas e censuras à direita
- Kaplan-Meier
- Ajuste de distribuições por máxima verossimilhança
- Comparação por AIC, BIC, ΔAIC e Peso de Akaike
- Weibull 2P e interpretação de β
- R(t), F(t), MTTF, B10, B50 e B90
- Relatório PDF completo por distribuição
- Página conceitual separando Análise de Vida de MTBF / Confiabilidade Operacional

Cada linha da base representa uma **observação de vida**, e não necessariamente um equipamento distinto.

Esta versão não acessa a base operacional do SCA e não grava dados em banco.
