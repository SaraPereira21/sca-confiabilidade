# SCA — Sistema de Confiabilidade de Ativos

Versão DEMO para validação acadêmica.

## Objetivo
Permitir a avaliação da metodologia estatística do SCA sem login e sem acesso à base operacional.

## Conteúdo
- Exercício Eixo Mecânico (30 falhas)
- Exercício Quebra de Bombas (28 falhas)
- Upload temporário de Excel/CSV
- Kaplan-Meier e distribuições candidatas
- AIC, ΔAIC, Peso de Akaike
- Weibull 2P, β, η, MTTF, B10/B50/B90
- Curvas R(t), f(t), h(t) e Q-Q Plot
- Meta de confiabilidade e missão
- PDF-resumo

## Privacidade
Esta versão não usa Supabase e não persiste uploads. Os dados enviados existem apenas durante a sessão do Streamlit.
